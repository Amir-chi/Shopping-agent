# سرراه: دستیار خرید حضوری در تهران

**نسخهٔ زنده: https://sarrah.liara.run**
(نیازی به اجرا روی سیستم خودتان نیست؛ پروژه روی همین آدرس بالاست.)

سرراه کمک می‌کند کالایی را که لازم داری **همین حالا، از نزدیک‌ترین مغازه** بخری. می‌گوید کدام فروشگاه نزدیک الان باز است، کدام بسته است و کی باز می‌شود، قیمت معمول کالا چقدر است و کجا شانس پیدا کردنش بیشتر است. داده‌ها از یک snapshot ترب است: حدود ۲۲۶ هزار کالا، ۳۳۲ هزار پیشنهاد قیمت و ۶٬۵۰۰ فروشگاه در تهران.

## قابلیت‌ها

- **همین الان، نزدیکم:** با موقعیت و ساعت، یک تصمیم می‌دهد: فروشگاه باز نزدیک، یا «نزدیک‌ترها بسته‌اند و فلانی ۳۰ دقیقهٔ دیگر باز می‌شود»، یا «محدودهٔ شیخ هادی ۱ کیلومتری‌ات است و شاید مغازه‌ای بیرون از ترب باز باشد». همه روی یک نقشه، با مسیر و پیام به مغازه.
- **دستیار گفت‌وگومحور:** سه حالت در یک گفت‌وگو: «همین الان»، «کدام مدل بخرم؟» (انتخاب و دلیل با هوش مصنوعی) و «ارزان‌ترین قیمت». گفت‌وگوهای قبلی به شکل کارت می‌مانند و ادامه‌دادنی‌اند.
- **صفحهٔ کالا:** فروشگاه‌ها به ترتیب نزدیکی یا قیمت، **نظر خودکار روی قیمت** («این قیمت به نظر درست نمی‌آید؛ معمولاً حدود …»)، برچسب قیمت‌های عجیب، لوازم مکمل سازگار با همان مدل، توضیح مشخصات به زبان ساده و بررسی ویدیویی.
- **ابزارهای کمک:** برنامهٔ جهیزیه با بودجه، پیدا کردن هدیه با سه سؤال، ست لباس، جست‌وجو با عکس، رنگ مناسب لوازم خانگی با عکس اتاق، مسیر خرید یک‌روزه برای چند کالا، مقایسه.
- **من این‌جام:** انتخاب نقطه روی نقشه و اعلان «فلان فروشگاه نزدیکت کالای فهرستت را دارد».
- **پیام به فروشنده و پنل فروشنده:** خریدار بدون حساب کاربری می‌پرسد «موجود است؟». فروشنده در پنل جواب می‌دهد و تقاضای بی‌جواب را می‌بیند.
- **کیفیت داده:** دسته‌ها با Codex دوباره مرتب شده‌اند، ۵۹۸ کالای در دستهٔ اشتباه جابه‌جا شده‌اند و غلط تایپی در جست‌وجو تصحیح می‌شود.
- **حالت آفلاین (PWA)** و چند تم ظاهری.

## صداقت داده و حریم خصوصی
قیمت‌ها «ثبت‌شده» هستند، نه لحظه‌ای. شماره‌تلفن‌های ساختگی دیتاست هیچ‌وقت قابل تماس نشان داده نمی‌شوند. قیمت‌های مشکوک کنار گذاشته می‌شوند. موقعیت دقیق کاربر ذخیره یا ثبت نمی‌شود. هوش مصنوعی فقط از میان کالاهای واقعی دیتابیس انتخاب می‌کند و قیمت و موجودی همیشه از دیتابیس می‌آید.

## ساختار کد

| مسیر | چه چیزی |
|---|---|
| `catalog/services.py` | مسیریاب API (`endpoint`) و کوئری‌ها |
| `catalog/now.py` | تصمیم «همین الان»: باز/بسته/زمان بازشدن و محدودهٔ پیشنهادی |
| `catalog/domain.py` | منطق خالص: ساعت کاری به وقت تهران، فاصله، تحلیل متن فارسی، مسیر |
| `catalog/assistant.py`, `catalog/ai.py` | دستیار هوش مصنوعی (درک درخواست، رتبه‌بندی) با جایگزین قاعده‌محور |
| `catalog/inquiries.py`, `catalog/seller*.py` | پیام خریدار به فروشنده و پنل فروشنده |
| `catalog/taxonomy.py` + `taxonomy.json`, `product_departments.json` | دپارتمان‌ها و اصلاح کالاهای در دستهٔ اشتباه |
| `catalog/models.py` | `Product`، `Shop`، `Offer` (ردیف خام ترب دست‌نخورده)، قیمت‌های فروشنده |
| `catalog.js`, `shopping.js`, `seller.js`, `reviews.js` | فرانت‌اند بدون فریم‌ورک (RTL، موبایل‌محور) |
| `ui.css`, `index.html`, `sw.js` | ظاهر، صفحهٔ اصلی و حالت آفلاین |
| `catalog/tests/`, `test_*.cjs` | تست‌های Django و فرانت‌اند |
| `deploy/`, `compose*.yaml`, `Dockerfile` | استقرار: Docker، Caddy و پراکسی HTTPS روی لیارا |

**فناوری:** Python/Django، PostgreSQL (جست‌وجوی متنی)، JavaScript بدون فریم‌ورک و بدون build، نقشه با کاشی‌های OpenStreetMap، Docker روی سرور ابری لیارا.
